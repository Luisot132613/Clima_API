# 🌦️ Clima API

Aplicação para consultar informações de clima em tempo real utilizando uma API externa.  
Este projeto foi desenvolvido em **JavaScript** e serve como base para estudos de consumo de APIs e manipulação de dados no frontend.

---

## 📋 Funcionalidades
- Consulta de dados meteorológicos em tempo real.
- Exibição de temperatura, condições climáticas e horário.
- Interface simples e responsiva.

---

## 🚀 Tecnologias utilizadas
- **HTML** → estrutura da página  
- **CSS** → estilização  
- **JavaScript** → lógica e consumo da API  
- **Fetch API** → requisições HTTP
